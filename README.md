# Java/Angular BI Reporting Layer for NYC Taxi Trip Analytics

Spring Boot REST API + Angular dashboard + PostgreSQL materialized views + Docker/Kubernetes.

The SQL loader creates a reproducible 1.2M-row TLC-style analytics dataset for local demos.
The project exposes aggregated reporting endpoints and an Angular dashboard with filters.

The performance figures in the portfolio description are target/illustrative measurements
and should only be claimed as measured after reproducing the benchmark.
